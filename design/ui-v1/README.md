# 云梦招商策略 · UI 设计方案 v1

`prompts/` 保留完整生成提示词。01–03 由对应初稿提示词和 `-v2.txt` 修订词共同生成，06 使用 `06-strategy-card-final.txt`。`drafts/` 保留被修订的初稿；交付包只包含 6 张最终图、预览页、说明和提示词。全部使用内置 imagegen，未用脚本重画或修改 PNG 像素。

## 一条连贯的示例路线

全国 → 云梦画像 → 锂电新材料 → 电解液配套（示例待完善环节）→ 城市匹配 → 新宙邦 → 策略卡。

这条路线用于 UI 和交互示范，不声称云梦实际缺少该产业环节，也不构成对企业投资意向的判断。现有华盛锂电投资记录应归入“已有项目”，与“潜在配套企业”分开呈现。

## 视觉规范与实现建议

- 地图为主体：保留现有地形、河流、行政界和流线的独立渲染，地图不烘焙进页面背景截图。流空间沿用彩色曲线、主要通道箭头、城市环形节点及云梦红色靶点。
- 全局导航固定三项：全国产业全景、云梦产业画像、流空间匹配。图中的 `场景 01/02/03` 是辅助标记，可在正式实现时保留为小字号。
- 表面 `#FCFCF9`，主文字 `#24342D`，辅助文字 `#778278`，边框 `#DCE3DB`，主操作 `#285846`；使用轻阴影和约 10 px 圆角。
- 人口流 `#3D83C6`、资本流 `#D69B33`、技术流 `#9370B6`；云梦目标 `#C44D46`。颜色由业务含义决定，各页沿用。
- 建议采用思源黑体／Microsoft YaHei，标题 24–28 px、卡片标题 18–20 px、正文 14–16 px、辅助信息 12–13 px。大屏运行时通过统一缩放调整，避免分别放大各组件。
- 参考设计基准 1920×1080；PNG 保留 imagegen 原生尺寸。原图用于视觉与信息层级参考，具体像素由组件和布局规则确定。
- 使用 8 px 间距体系；外边距 24 px，卡片内边距 20–24 px，区块间距 16–24 px。保持地图的可用宽度，侧栏在窄窗口中折叠为可切换抽屉。
- 两个弹出层共用遮罩、标题、关闭、底部操作区。关闭后回到原来的筛选和地图位置。

## 数据与事实边界

1. GDP、增速、行业分布、目标缺口、匹配排名和评分属于 UI 示例；对应区域已用“示意”或“待接入”标记。不能将图片上的数字直接写进业务数据表。
2. 当前项目已有流线数据及云梦矢量继续作为实现依据；图片里的地图字形、线条和点位只用于版式参考，不作为 GIS 数据。
3. 画稿中的“已有环节／待完善环节”用于示例。真实产业链分类、园区范围和企业位置仍以项目后续资料为准。
   铜箔与电解液是面向电池制造的并列材料环节，不能从示意图推导两家企业之间存在上下游交易。
4. 新宙邦、天赐材料和华盛锂电是真实企业。模型图中企业图标属于视觉占位，实施时使用经核对的标识或统一文字头像。
5. 工商详细字段和股东结构未得到完整资料，保留待接入状态；不编造法人、注册资本、股东名称或持股比例。
6. 策略卡中的土地、用电、算力、政策等为洽谈方向；不写成优惠承诺，不虚构价格、税收减免或补贴。
