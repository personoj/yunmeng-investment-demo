# 云梦招商平台标识

`yunmeng-platform.png` 为本平台原创标识，由内置 imagegen 生成并保留原始透明 PNG。视觉采用秦简展开、云水连通和向上生长的形态；深青绿 `#245D50` 配暖金 `#BA995B`，与地形底图协调。它是平台设计，不是政府徽章或已发布的官方标识，也没有将这组颜色称为政府标准色。

设计参考来自湖北省知识产权局公开的[云梦县地理标志与文旅融合新闻](https://zscqj.hubei.gov.cn/fbjd/szdt/202609/t20260930_6026226.shtml)：云梦的文化视觉涉及竹简、云纹和水波纹。未直接复制文旅线路的圆形徽章。配色由本项目自行制定。

完整生成提示词保存在 `imagegen-prompts.json`。页面使用该 PNG 作为标题前的独立标识，替代旧县域轮廓。后续替换同名文件即可更新。
