# 产业链产品配图

三张素材均使用内置 imagegen 生成，作为产业类别的写实产品图。保留原始 PNG 和透明通道，生成提示词见 `imagegen-prompts.json`。

| 文件 | 环节与主题 |
| --- | --- |
| wafer.png | 电子信息上游：硅片、晶圆 |
| chip.png | 电子信息中游：集成电路、芯片 |
| devices.png | 电子信息下游：智能手机、计算机 |

素材不附特定企业商标，不能用来证明某一企业生产了图中产品。前端 `StageVisual` 在全国产业链及云梦图谱内使用等比图片容器，后续替换同名文件不需要更改布局。
